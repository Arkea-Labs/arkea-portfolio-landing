# Landing Page de Alta Conversão (`arkea-portfolio-landing`)

Aplicação demonstrativa de portfólio desenvolvida em **Next.js 15 (App Router)**, **TypeScript** e **Tailwind CSS**, projetada para demonstrar arquitetura de conversão direta via **WhatsApp** e **Pré-Reserva / Diagnóstico no Site**.

## Cenários Comerciais Inclusos

1. **Aura Clínica Dermatológica & Estética (São Paulo)**
   - **Paleta:** Porcelana Fria (`#F8F9FA`), Cinza Mineral (`#ECEFF1`), Ardósia Profunda (`#182226`), Verde Eucalipto Escuro (`#1F4E46`) e Sálvia Suave (`#D7E4E0`).
   - **Tipografia:** `Newsreader` (títulos editoriais) + `Plus Jakarta Sans` (corpo e controles).
   - **Ferramenta Interativa:** Planejador de protocolos dermatológicos e tecnologias a laser em `R$` com cálculo automático de abatimento de consulta combinada, duração em cabine e prévia da mensagem para WhatsApp (`wa.me`).

2. **Vértice Sistemas & Operações B2B**
   - **Paleta:** Papel Técnico (`#F3F4F6`), Branco Puro (`#FFFFFF`), Grafite Naval (`#121820`), Azul Cobalto (`#1D4ED8`) e Cinza Chumbo (`#4B5563`).
   - **Tipografia:** `Plus Jakarta Sans` em toda a hierarquia técnica.
   - **Ferramenta Interativa:** Calculadora de escopo fechado e prazo de implantação em semanas conforme gargalos operacionais, porte da equipe e ritmo de entrega.

## Como Executar

```bash
npm install
npm run dev
```
